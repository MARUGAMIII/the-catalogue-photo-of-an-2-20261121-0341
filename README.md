A catalogue photograph of an impossible gadget: the BS-9000 Banana Straightener, a brushed-steel countertop appliance that takes a curved banana in on the left and ejects a perfectly straight banana on the right — "STRAIGHTNESS 100%". One accessory: a single curved banana resting on the studio floor. The image is drawn deterministically from code, so the joke reads at a glance with no caption explaining it.

## Run it

```sh
python3 main.py
```

Python 3.13, standard library + Pillow only, no network. The run writes `/output/entry.png` — a whole PNG, 1024×1024 pixels, at most 1 MiB — and is deterministic: two runs write the same bytes.
